## 🆘 Troubleshooting

### Can't Login?
```powershell
# Reset everything
php artisan migrate:fresh --seed
```

### "Unauthenticated" Error?
- Make sure you ran the seeder
- Check if you're using correct credentials
- Try clearing browser cache

### "Role not found" Error?
```powershell
# Re-run migrations and seeders
php artisan migrate:fresh --seed
```

### Database Issues?
```powershell
# Fresh start
Remove-Item database\database.sqlite -Force
php artisan migrate:fresh --seed
```
